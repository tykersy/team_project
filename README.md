## 🔗 Linked - HR 통합 관리 시스템

## 📌 프로젝트 소개
Linked는 사내 인사, 근태, 일정, 메신저 기능을 하나로 통합한 HR 관리 시스템입니다.  
관리자는 직원 현황과 근태 데이터를 한눈에 확인할 수 있고, 직원은 출퇴근, 일정 관리, 메신저, 계약 정보 확인 등을 사용할 수 있습니다.

## 🗓️ 개발 기간
2026.05 ~ 2026.07

## 👥 팀원 및 역할
| 이름 | 담당 기능 |<br/>
| 혜지 | 관리자 |<br/>
| 효경 | 메인 UI, 조직도, 공지사항 |<br/>
| 재민 | 로그인, 회원가입, 마이페이지, 메신저 |<br/>
| 우중 | 근태, 인사, 캘린더, 메신저 |

## ✅ 주요 기능

### 관리자 기능
- 통합 대시보드
- 부서별 조직도 관리
- 사원 정보 관리
- 근태 현황 확인
- 급여 및 결재 현황 관리

### 직원 기능
- 로그인 / 회원가입
- 개인 대시보드
- 출근 / 퇴근 처리
- 근태 기록 조회
- 개인 일정 / 부서 일정 관리
- 마이페이지
- 전자 근로계약서 확인 및 서명

### 캘린더
- 개인 일정 등록 / 조회
- 부서 일정 등록 / 조회
- 관리자 및 팀장 권한 기반 일정 관리

### Linked Messenger
- 사원 목록 조회
- 1:1 채팅
- 그룹 채팅
- 프로필 조회
- 근무 상태 표시
- 즐겨찾기 기능
